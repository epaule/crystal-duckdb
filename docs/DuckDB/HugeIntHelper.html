    module DuckDB::HugeIntHelper

    Overview

    Converts between Crystal's native Int128 and DuckDB's HUGEINT, which the C API exposes as a split {upper : Int64, lower : UInt64} struct.

    The two halves are round-tripped through a 16-byte big-endian buffer so the 128-bit value is reassembled with the correct sign and magnitude.
