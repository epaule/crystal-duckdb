    • DuckDB::Interval

    Overview

    Represents the INTERVAL data type of SQL within DuckDB.

    DuckDB stores intervals as three independent fields — #months, #days, and #microseconds — because the length of a month or day is not fixed. This is why converting to a Time::Span may require approximating months as days.

    def to_span(approx_months : Int | Nil = nil) #

    Creates a Time::Span from this DuckDB::Interval.

    When #months is non-zero, approx_months must give the number of days to count per month; otherwise a DuckDB::Exception is raised because months have no fixed length. Raises if the result exceeds the range of Time::Span.
