    struct DuckDB::Timestamp

    • DuckDB::Timestamp
    • Struct
    • Value
    • Object

    Overview

    Represents the TIMESTAMP data type of SQL within DuckDB (a Date plus a TimeOfDay, with microsecond resolution and no timezone).

    Component accessors such as #year, #hour, and #microsecond are delegated to the underlying #date and #time_of_day.
